# swamp-markdown-corpus

[swamp](https://swamp.club) extension `@mgreten/markdown-corpus` — ingest a
directory of dated markdown notes into typed, queryable structure.

📖 **Extension documentation:** [extensions/models/README.md](extensions/models/README.md)

📦 **Install:** `swamp extension pull @mgreten/markdown-corpus`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable extension lives under [extensions/models/](extensions/models/).
